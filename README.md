# NYRA Guard - Anti-Bot & Liquidity Shield 🛡️🔒

An advanced security interface protocol designed to protect the **$NYRA** ecosystem from malicious bot activity on Solana.

## 🎯 Features
- **Anti-Sniper Protocol:** Mitigates automated sniping at launch.
- **Max Transaction Controller:** Limits individual wallet impact on price.
- **Live Security Dashboard:** Real-time monitoring of contract interactions.

## 🔒 Security Policy
This repository showcases the **Frontend User Interface** of our security toolkit. Core smart contract configurations remain private to prevent exploits.
